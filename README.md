# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project focuses on **E-Commerce Sales and Customer Analytics** using an end-to-end data analytics workflow.

The project started with a raw e-commerce dataset that was cleaned and transformed using **Microsoft Excel**, analyzed using **MySQL**, visualized through an interactive **Power BI dashboard**, and further explored using **Python for Exploratory Data Analysis (EDA) and data visualization**.

The objective of this project is to identify important sales, profit, customer, product, category, regional, discount, and payment-related insights that can support data-driven business decisions.

---

## 🎯 Project Objectives

* Clean and prepare raw e-commerce data.
* Handle missing values and inconsistent data.
* Perform data analysis using MySQL.
* Analyze sales and profit performance.
* Identify top-performing products and categories.
* Analyze regional sales performance.
* Understand customer satisfaction.
* Analyze payment methods and order behavior.
* Study the relationship between sales, cost, discount, quantity, and profit.
* Build an interactive Power BI dashboard.
* Perform exploratory data analysis using Python.
* Create meaningful visualizations for business insights.
